# Further FusDenseNet and controlled-physiology experiments

3 November 2026, Asia/Kolkata. Previous deployed baseline: 52.55% full-test accuracy, macro F1 0.4492, disgust recall 12.66%; checksum dbc4a9f9293fb4e1b28ae249958964cfe12e1b3b17a18f7e75bea77925b7a4ba.

Full-network fine-tuning starts from that checkpoint. All FusDenseNet parameters remain trainable; architecture and seven output classes are unchanged. Fixed training/validation pixels are verified. AdamW LR 0.00005, 12 requested extra epochs, patience 5, 100-minute boundary budget, CPU, batch 64. Training-only replacement sampling uses inverse-frequency power 0.5, with milder CE class-weight power 0.25. This increases rare-class exposure without discarding any validation/test errors. Augmentation remains training-only. Optimizer is restarted explicitly.

Epoch snapshots are preserved. Candidate selection uses validation only: prefer candidates at least matching initial validation accuracy and macro F1, then maximize 0.75 × macro F1 + 0.25 × disgust F1. Disgust F1 balances missed disgust examples against false disgust predictions. If no candidate meets those constraints, report that fact and retain the better existing checkpoint unless a separately documented test/deployment check supports a replacement. There is no promised accuracy target or exact paper reproduction. The test corpus remains historically inspected, not fresh or identity-disjoint.

For real physiology, pooled games no longer define the main task. Separate QWOP (Angry/Happy) and CBAAD (Bored/Stressed) experiments hold game identity constant. Primary inputs are centered **fixed 30-second** slices within qualifying annotations, with real EEG/ECG from the same recording. Duration is therefore constant too. Classifiers and scaling are fitted only on training participants in leave-one-participant-out evaluation. Majority, constant-game and duration-only controls are reported. Both offset signs are preserved; the favorable convention is not chosen after scoring. Whole ≥15s intervals and ≥60s feasibility are separate sensitivity analyses. Small cohorts, short-window HRV, uncertain annotation alignment and physiological artifacts limit interpretation. No face, disgust or raga-response data are invented.

The controlled analyses remove game identity as an explanation within each task. They do not establish absence of all possible confounds or clinical validity. Independent source-recording/window/fold audits are required before delivery.

After the first ordinary-BatchNorm fine-tuning epoch regressed on validation, a second training recipe retains the existing BatchNorm running references while keeping affine parameters, dropout and all other parameters trainable. This tests whether rare-class sampling and augmentation shifted the inherited feature statistics. It uses LR 0.0001, sampling power 0.5 and unweighted smoothed CE. The first recipe and its regressions remain recorded. Selection additionally requires validation disgust F1 not to decrease; any deployment must improve actual disgust F1 as well as overall accuracy and macro F1, without lower disgust recall. No test score informs these training choices.

Spatial v3 further trials retain original mechanisms and add a normalized 768-feature early stem path. MLP experiments include natural features, training flips and stronger inverse-frequency CE power 0.75. Validation floors apply before selecting a final candidate. Full v3 fine-tuning retains BN running references. After that run finishes, the final state and arithmetic mean of up to its last three full states may receive BN-buffer recalibration using only natural unaugmented training images. These candidates are compared on the same fixed validation split; no test access selects the recipe. Every candidate and rejected score is retained.

Before final new test access, flip TTA is accepted only if fixed-validation macro F1 improves by >0.002 while validation accuracy and disgust F1 do not decrease. Temperature fitting cannot change argmax labels. This policy retains all test errors, not a confidence-filtered accuracy.
